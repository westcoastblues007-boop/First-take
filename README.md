# Jazz Guitar Lab

中級〜上級者向けのジャズギター学習ページです。

- **コード・ボイシング**：シェル / ドロップ2 / ドロップ3 / ドロップ2&4 / テンション / ルートレス / クォータル。全12キーに移調でき、度数・音名表示を切り替え可能。図をクリックするとストラム、ボタンでアルペジオ再生。
- **スケール**：メジャー・モード、メロディック・マイナーのモード（オルタード、リディアン♭7 など）、ハーモニック・マイナー系、ディミニッシュ、ホールトーン、ビバップ、ペンタ/ブルース。0〜15フレットの指板図で、5フレット単位のポジション表示・再生ができます。

音はブラウザ内で合成（Karplus-Strong）しているため、音源ファイルは不要です。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

GitHub Pages で公開する場合：リポジトリの **Settings → Pages** で、ブランチとルート（`/`）を選択してください。

## 構成

```
index.html      ページ本体
css/style.css   スタイル（ライト/ダーク対応）
js/theory.js    度数・音名・移調のヘルパー
js/data.js      ボイシング & スケールのデータ（C 基準）
js/audio.js     撥弦シンセ
js/app.js       UI
```

ボイシングを追加するときは `js/data.js` に、ルート C の時のフレット（6弦→1弦、`null` はミュート）と各弦の度数を書きます。
